# Store Owner CRM Dashboard

This workspace will host the single-owner CRM frontend (Vite + React + Tailwind CSS + Supabase Realtime client).

## Workspaces & Views
1. **Live WhatsApp Chat**: High-speed WhatsApp customer support, kit card injection, and quick order creation.
2. **Kits & Catalog Browser**: Search, filter, and sync latest 26/27 football kits.
3. **Order Pipeline**: Kanban board for customer orders (Deposit -> Printing -> Shipped -> Delivered).
4. **Settings & Onboarding**: Meta Embedded Signup status and API keys.

Refer to the complete technical and UI specification in [docs/FRONTEND_CRM_SPEC.md](../docs/FRONTEND_CRM_SPEC.md).
